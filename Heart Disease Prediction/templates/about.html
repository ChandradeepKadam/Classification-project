About Project

Heart Disease Prediction System

An AI and Machine Learning based web application for heart disease prediction using classification techniques.

Project Overview

The Heart Disease Prediction System is a web-based Artificial Intelligence and Machine Learning project developed to demonstrate classification techniques on heart disease data.

The application takes patient-related dataset attributes as input and uses trained machine learning models to classify the input into a heart disease or no-heart-disease category.

The project combines Python, Scikit-learn, Pandas, Flask, Bootstrap and SQLite to create a complete machine learning web application.

Technologies Used

Python

Main programming language used for machine learning and backend development.

Scikit-learn

Used to build, train and evaluate classification models.

Flask

Used to create the web application and backend routes.

Pandas

Used for dataset loading, processing and manipulation.

SQLite

Used to store prediction history locally.

Bootstrap

Used to create the responsive web interface.
